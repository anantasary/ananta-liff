# 糖活ぶっちゃけおしゃべり会 事前アンケート

| ファイル | 役割 |
|---|---|
| `index.html` | 参加者が答えるページ（スマホ向け・Q1で自動分岐） |
| `live.html` | 投影用のライブ集計画面（5秒ごとに自動更新・←→キーで質問を切り替え） |
| `questions.js` | 質問の内容と保存先URL（`GAS_URL`） |
| `gas/Code.gs` | 回答をGoogleスプレッドシートに保存するスクリプト |

## 保存先の準備（最初に1回だけ）
1. Googleスプレッドシートを新規作成（名前は自由）
2. メニュー「拡張機能」→「Apps Script」を開く
3. 中身を全部消して `gas/Code.gs` の内容を貼り付け、保存
4. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 表示された「ウェブアプリURL」を `questions.js` の `GAS_URL` に貼り付ける

回答はスプレッドシートの「回答」シートに1人1行で保存されます。
テスト回答は、その行を削除すれば集計画面からも消えます。
